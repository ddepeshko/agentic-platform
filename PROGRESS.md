## Модуль 0. Старт і вимоги

### 2026-10-08
- Створено папку проєкту, додано `HANDOFF.md`, `CLAUDE.md` (правила менторства), цей файл.
- **Рішення:** стек і програма з `HANDOFF.md`, крім моделі (див. нижче).
- **Рішення (зміна стеку): модель.** Замість платного Anthropic API беремо безкоштовні провайдери через **OpenAI-сумісний API** (npm `openai`). Основний провайдер: **Google Gemini** (безкоштовний тариф, ключ з AI Studio). Запасний: **Ollama** локально (16 GB RAM, моделі ~7–8B). Провайдер задається через `.env`: `LLM_BASE_URL`, `LLM_API_KEY`, `LLM_MODEL`.
  - *Чому:* безкоштовно; не прив'язуємося до одного SDK, що готує ґрунт для model gateway з модуля 11.
  - *Ризики:* ліміти безкоштовного тарифу; Google може використовувати дані з безкоштовного тарифу, тож приватних даних не відправляємо; безкоштовні моделі слабші в tool calling.
- **Зроблено (ментор на прохання користувача):** git (гілка `main`), npm (ESM), TypeScript 6 strict, ESLint (flat config + typescript-eslint), папки `src/core`, `src/platform`, `src/domain`, `evals/`, `.gitignore` з `.env`.
- **Рішення: `tsx` для запуску + `tsc --noEmit` для перевірки типів.** `tsx` запускає TS без збірки (швидкий цикл), але типи не перевіряє, тому `tsc` окремим скриптом `typecheck`. Збірку в `dist/` додамо в модулі 11 (Docker).
- **Рішення: `moduleResolution: "Bundler"`** (`module: "ESNext"`). Імпорти без розширень і без `index`: `import { config } from "./platform"`.
  - *Чому:* звичний синтаксис (як в Angular), `tsx` (esbuild) такі шляхи розуміє.
  - *Ціна:* чистий `node` такий код не запустить, тому для продакшн-збірки в модулі 11 потрібен бандлер (`tsup`/`esbuild`).
  - *Відкинуто:* `paths` у tsconfig (теж потребує інструмента при збірці), `imports` у package.json (`#platform`, незвичний синтаксис).
- **Модель: `gemini-3.8-flash`.** `gemini-2.5-flash` є в `/models`, але для нових користувачів повертає 404. Висновок: список моделей ≠ доступність, перевіряти реальним запитом.
- Перший виклик моделі працює. Помічено: `total_tokens` > `prompt + completion`, різниця — це reasoning (thinking) токени, і вони теж оплачуються (→ модуль 7).
